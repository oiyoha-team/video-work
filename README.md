# 오이요하 퍼포먼스 영상 자동화

레퍼런스 영상을 분석해 자사 제품용 퍼포먼스 광고 영상을 만드는 도구입니다.

| 모듈 | 화면 단계 | 상태 |
|---|---|---|
| 1 기획 자동화: 레퍼런스 분석 → 제품 입력 → 스크립트 생성·수정 → 확정 | 1~4 | ✅ 사용 가능 |
| 2-A 비주얼: 장면 이미지 생성 → 영상화 | 5 | 🟡 화면·흐름 완성, 임시 엔진(mock) |
| 2-B 사운드: 대사 음성(TTS) | 5 (비주얼과 동시) | 🟡 화면·흐름 완성, OS 기본 음성 |
| 3 결과물 다운로드: 클립·음성·이미지·자막 전체/선택 다운로드 → 직접 편집 | 6 | ✅ 사용 가능 |
| 승인 알림: 단계 완료 시 [진행]/[수정] | 전체 | ✅ 앱 알림 · Flow 연동 예정 |

- 전체 흐름 한눈에 보기: **[WORKFLOW.html](WORKFLOW.html)** (브라우저로 열기)
- 설계와 모듈 간 데이터 형식: [PLAN.md](PLAN.md)

## 처음 설치하기 (스타터팩)

미리 설치해 둘 프로그램은 없습니다. 아래 파일 하나만 실행하면 필요한 것을 확인하고, 없는 것은 자동으로 설치합니다.

| | Windows | Mac |
|---|---|---|
| 1. 설치 (처음 한 번) | `1_설치하기.bat` 더블클릭 | `1_설치하기.command` 더블클릭 |
| 2. 실행 (매번) | `2_실행하기.bat` 더블클릭 | `2_실행하기.command` 더블클릭 |

**스타터팩이 하는 일**
0. **OS를 자동 판별합니다.** Mac이면 Homebrew·`.command` 방식, Windows면 winget·`.bat` 방식으로 진행합니다.
   - 다른 OS용 파일을 실행해도 맞는 방식으로 자동 전환됩니다. 예를 들어 Windows에서 `.command`를 실행하면 Windows 설치로 넘어갑니다.
   - Mac은 Apple Silicon과 Intel을 구분하고, 인터넷에서 받은 파일에 붙는 격리 표시를 풀고 실행 권한을 줍니다.
1. 필수 프로그램을 확인하고, 없으면 설치합니다.
   - Python 3.10 이상 (없으면 3.12 설치)
   - Node.js 18 이상 (없으면 LTS 설치)
   - Visual C++ 런타임 (Windows만, 음성 인식 엔진에 필요)
   - ffmpeg는 Python 패키지에 포함되어 있어 따로 설치하지 않습니다.
2. Python 가상환경을 만듭니다. 다른 PC에서 복사해 온 `.venv`가 있으면 확인한 뒤 새로 만듭니다.
3. Python 패키지를 설치합니다.
4. 화면을 빌드합니다.
5. `.env` 파일을 만들고 Claude API 키를 묻습니다. 없으면 Enter로 건너뛸 수 있습니다.
6. 음성 인식 모델(약 500MB)을 미리 받습니다. 받을지 선택할 수 있습니다.
7. 최종 점검 후 바로 실행할지 묻습니다.

여러 번 실행해도 안전합니다. 설치 중 오류가 나면 창을 닫고 다시 실행하세요. 이미 설치된 것은 건너뜁니다.

**설치 중 알아둘 것**
- Windows: Node.js나 Visual C++ 런타임을 설치할 때 관리자 권한 창이 뜨면 '예'를 누르세요.
  - winget이 없는 구형 Windows 10은 Microsoft Store에서 '앱 설치 관리자'를 먼저 설치해야 합니다.
- Mac: Homebrew를 설치할 때 Mac 로그인 비밀번호를 묻습니다.
  - 더블클릭해도 실행되지 않으면 터미널에서 `bash 1_설치하기.command`로 실행하세요.

**API 키:** 나중에 넣으려면 `.env` 파일을 열고 아래 줄에 키를 붙여 넣은 뒤 프로그램을 다시 실행하세요.
```
ANTHROPIC_API_KEY=sk-ant-...
```
키가 없으면 **mock 모드**로 동작합니다. 음성 인식(대사 추출)은 그대로 되고, 장면 분석이나 스크립트 생성처럼 Claude가 필요한 기능은 직접 입력하거나 레퍼런스를 복사한 초안으로 대체됩니다.

## 팀원에게 배포하기

1. 저장소를 받습니다: `git clone https://github.com/oiyoha-team/video-work.git`
2. **`.env` 파일은 저장소에 없습니다.** API 키가 노출되지 않도록 git에서 제외했습니다.
   - 담당자에게 받은 `.env`를 프로젝트 폴더(`1_설치하기` 파일이 있는 곳)에 넣고 설치하면, 설치 파일이 그 키를 그대로 씁니다.
   - `.env`가 없으면 설치 중에 API 키를 묻습니다. 키가 `sk-ant-usr-`로 시작하면 워크스페이스 ID(`wrkspc_…`)도 이어서 묻습니다.
   - `.env`는 메신저 개인 메시지처럼 공개되지 않는 경로로만 전달하세요. 공개 저장소나 단체방에 올리면 키가 무단 사용될 수 있습니다.
3. `1_설치하기`를 실행하고, 이후에는 `2_실행하기`만 실행합니다.

## 실행하기

`2_실행하기`를 실행하면 브라우저에서 http://localhost:8000 이 열립니다.
- 실행 창을 닫으면 프로그램도 종료됩니다.
- 이미 실행 중이면 브라우저만 다시 엽니다.

> `.env`를 수정했다면 실행 창을 닫고 다시 실행해야 반영됩니다.

## 사용 흐름

1. **레퍼런스 분석**: 3분 이하 영상을 올립니다.
   - 2초 단위로 장면, 대사, 자막, 역할을 추출하고, 영상 전체의 말투·컨셉·화자 페르소나도 정리합니다.
   - 바로 이어지는 구간의 대사가 **완전히 같을 때만** 한 구간으로 합칩니다.
   - 대사는 **문장 단위**로 끊어 한 줄에 한 문장씩 보여 줍니다.
   - 분석 대상은 **대사와 장면**입니다(자막은 분석하지 않음).
   - **장면 상세:** 구간마다 피사체·인물, 행동·표정, 장소·배경, 구도·카메라 앵글, 조명·색감, 제품 노출을 추출합니다. 영상 전체의 **비주얼 스타일**도 함께 정리합니다.
   - 장면 분석은 `scene_analysis/` 폴더에 따로 저장했다가, 영상 제작 단계에서 레퍼런스와 비슷한 이미지를 만들 때 씁니다.
     - 마침표(.), 물음표(?), 느낌표(!)를 문장 끝으로 봅니다.
     - 한 문장은 한 구간에만 들어갑니다.
   - 결과는 모든 칸을 직접 고칠 수 있습니다.
   - 영상 비율은 레퍼런스에서 자동으로 감지하고, 1:1 / 4:5 / 16:9 / 9:16 중에서 바꿀 수 있습니다.
2. **제품 정보**: 제품 정보 입력서 양식을 따릅니다.
   - **입력 항목:** 1 제품명, 2 제품 USP, 3 제품 특징, 4 사회적·수치적 근거 및 권위, 5 제품 지칭 키워드, 6 들어가면 안 되는 표현, 7 상세페이지 URL, 그리고 기타 메모
   - **이미지:** 연출컷과 누끼컷을 각각 **최대 5장**까지 넣을 수 있고, 여러 장을 한 번에 고를 수 있습니다.
   - **입력 방법:**
     - 직접 입력
     - 저장된 제품 불러오기: 한 번 [제품 저장]을 해 두면 다음 기획안에서 다시 쓸 수 있습니다.
     - md 파일 업로드: [템플릿 받기]로 받은 양식([product_template.md](product_template.md))을 쓰면 정확하게 읽습니다. 6번이 '없음'이면 빈 값으로 처리합니다.
3. **스크립트 작성**: 레퍼런스 구조와 말투를 유지한 채 제품 내용으로 바꾼 **대사 스크립트**가 생성됩니다.
   - 화면에는 레퍼런스 대사와 자사 대사만 나란히 보입니다.
   - 대사는 레퍼런스 문장과 **1:1**로 바뀝니다(한 줄 = 한 문장). 문장 수가 다르면 빨간색으로 표시됩니다.
   - 왼쪽에서 직접 수정하거나, 오른쪽 Claude 대화창에서 요청합니다. 대화창의 변경안은 [적용]을 눌러야 반영됩니다.
4. **기획 확정**: 최종본은 **대사만** 한 줄에 한 문장씩 보여 줍니다. [TXT 저장]이나 [전체 복사]로 가져갑니다.
   - [영상 제작으로 넘기기]를 누르면 5단계가 시작됩니다.
5. **영상 제작**: 비주얼(장면 이미지 → 영상화)과 사운드(대사 음성)가 동시에 진행됩니다.
   - 이미지를 만들기 전에 **장면 브리프**(영어 이미지 프롬프트와 카메라 움직임)를 만듭니다. 재료는 장면 분석, 자사 대사, 제품 정보입니다.
   - 제품 연출컷·누끼컷은 장면에 배정하지 않습니다. 제품 외형을 정확히 그리기 위한 **참고 자료**로 모두 넘깁니다.
   - 장면별로 이미지·클립·음성을 확인하고 하나씩 다시 만들 수 있습니다.
   - 음성은 **자사 스크립트 문장마다 파일 하나**로 만들어집니다(`scene01_1.wav`, `scene01_2.wav` …).
     - 레퍼런스 영상의 음성은 대사 추출에만 쓰고, 파일로 내보내지 않습니다.
     - 지금은 OS 기본 음성으로 만든 임시 음성입니다. 일레븐랩스·타입캐스트 연동 자리를 마련해 두었습니다(`SOUND_ENGINE`).
   - 문장 음성 길이의 합이 장면 길이보다 길면 빨간색으로 표시됩니다.
6. **결과물 다운로드**: 장면별 영상 클립, 음성(TTS), 이미지, 편집용 자료를 받아 편집 툴에서 직접 완성합니다.
   - **받는 방법:** 전체 ZIP, 묶음별 ZIP(영상만, 음성만 등), 체크한 파일만 ZIP, 파일 하나씩 받기를 모두 지원합니다.
   - **파일 이름:** `scene01`, `scene02` … 처럼 장면 순서대로 붙어 있습니다.
   - **편집용 자료:**
     - `timeline.csv`: 장면별 시작·끝 시간, 대사, 파일 이름이 정리되어 있습니다.
     - `subtitles.srt`: 전체 타임라인 기준 자막입니다.

> 현재 이미지·영상은 레퍼런스 프레임과 제품 이미지에 줌 효과를 준 **임시 결과물**입니다. 음성도 Windows나 Mac에 내장된 기본 음성입니다. 실제 AI 엔진을 연결하면 같은 화면에서 그대로 바뀝니다.

## 승인 알림 (원격 조정)

자동으로 도는 단계가 끝날 때마다 **승인 요청**이 생깁니다. 대상은 레퍼런스 분석, 스크립트 작성, 이미지 생성, 클립·음성 준비입니다.
- 앱 상단의 🔔 알림 센터나 해당 단계 화면의 배너에서 **[진행]** 또는 **[수정]**을 누릅니다.
  - **진행**: 다음 단계가 자동으로 시작됩니다.
  - **수정**: 코멘트가 해당 단계 화면에 표시됩니다. 스크립트 단계에서는 Claude가 코멘트를 반영해 수정본을 만들고 다시 승인을 요청합니다(API 키 연결 시).
- **Flow 메신저 연동(예정):** 같은 승인 요청이 Flow로 전송되고, 「진행 a1b2c3」 또는 「수정 a1b2c3 내용」으로 답하면 PC 앞에 없어도 다음 단계가 실행됩니다.
  - 응답을 받는 입구 `POST /api/flow/webhook`과 답장 해석기는 이미 구현되어 있습니다.
  - Flow API 문서를 받으면 `backend/notify/flow.py`의 전송 부분만 채우면 됩니다.

## 설정 (.env)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (비어 있음) | Claude API 키 |
| `ANTHROPIC_WORKSPACE_ID` | (비어 있음) | 키가 `sk-ant-usr-`로 시작할 때만 필요. 콘솔의 워크스페이스 ID(`wrkspc_…`) |
| `CLAUDE_MODEL` | `claude-opus-5-5` | 분석·생성에 쓰는 모델 |
| `STT_ENGINE` | `local` | 음성 인식 엔진. 현재는 `local`(로컬 Whisper)만 구현되어 있음 |
| `WHISPER_MODEL` | `small` | `tiny` / `base` / `small` / `medium` / `large-v3` (클수록 정확하지만 느림) |
| `VISUAL_ENGINE` | `mock` | 이미지·영상 엔진 (실제 엔진 연결 예정) |
| `SOUND_ENGINE` | `system` | `system`(OS 기본 한국어 음성) / `silent`(무음) |
| `FLOW_*` | (비어 있음) | Flow 메신저 연동 설정 (연동 예정) |
| `PUBLIC_BASE_URL` | `http://localhost:8000` | 알림 메시지의 링크 주소 · 외부 접속 주소 |

로컬 Whisper는 첫 실행 때 모델을 내려받습니다(small 기준 약 500MB). 그래서 첫 분석은 시간이 더 걸립니다.

## 개발 모드

화면을 수정하면서 바로 확인하려면 터미널 두 개를 엽니다.
