2승인 루프 — 자리에 없어도 Flow로 원격 조정

1. 자동 단계 완료
  • 분석, 스크립트, 이미지, 클립·음성
2. 승인 요청 생성
  • 6자리 코드 발급
  • 요약 + 화면 링크
3. 알림 발송
  • 앱 상단 🔔 알림 센터
  • Flow 메신저 (연동 예정)
4. 사람이 응답
  • 앱: [진행] / [수정]
  • Flow: 「진행 a1b2c3」 /
    「수정 a1b2c3 내용」
5. 같은 동작 실행
  • 어디서 눌러도
    workflow.resolve_gate()
▶ 진행 — 다음 단계가 자동으로 시작됩니다. 예) 스크립트 승인 → 기획 확정, 이미지 승인 → 영상화 시작, 클립·음성 승인 → 제작 확정 · 다운로드
✎ 수정 — 코멘트가 해당 단계 화면에 표시됩니다. 스크립트는 Claude가 코멘트를 반영해 수정본을 만들고 다시 승인을 요청합니다 (API 키 연결 시).
원격 응답 경로
Flow 메신저→POST /api/flow/webhook→게이트 처리→다음 단계 자동 실행
이 PC의 서버가 외부에서 보이지 않으므로 Flow 기능에 따라 둘 중 하나로 연결합니다: (A) Flow가 버튼 응답을 웹훅으로 보내주면 → 터널 주소(PUBLIC_BASE_URL)로 수신 / (B) 웹훅이 없으면 → 서버가 Flow 채팅방 답장을 주기적으로 읽어 처리. 웹훅 입구와 답장 해석기는 이미 구현되어 있고, Flow API 전송 부분만 남아 있습니다.

4설치 · 실행 (OS 자동 판별)

Windows
  • 1_설치하기.bat → winget으로 Python · Node.js · VC++ 런타임 자동 설치
  • 2_실행하기.bat → 서버 + 브라우저
  • Mac용 파일을 실수로 실행해도 자동으로 Windows 방식으로 전환
macOS
  • 1_설치하기.command → Homebrew로 Python · Node.js 자동 설치 (Apple Silicon / Intel 자동 인식)
  • 2_실행하기.command → 서버 + 브라우저
  • 시스템 음성(say), 실행 파일 이름 등 앱 내부도 Mac 방식으로 동작
